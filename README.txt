# Employee Attrition Analysis## Project OverviewThis project analyzes employee attrition using machine learning techniques.The goal is to identify the key factors that cause employees to leave the company.## DatasetIBM HR Analytics Employee Attrition Dataset## Tools and TechnologiesPythonPandasSeabornMatplotlibScikit-LearnJupyter Notebook## Steps Performed1. Data Loading2. Data Cleaning3. Exploratory Data Analysis4. Feature Engineering5. Model Training using Random Forest6. Model Evaluation7. Feature Importance Analysis## ResultsThe model predicts employee attrition with good accuracy.Key factors affecting attrition include:- Overtime- Job Satisfaction- Monthly Income- Years at Company## Business InsightsEmployees working overtime and having low job satisfaction are more likely to leave the organization.## Future Improvements- Use advanced models like XGBoost- Build a dashboard using Streamlit
